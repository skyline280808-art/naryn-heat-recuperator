# Компактный рекуператор тепла для Нарына

Проект энергосбережения для холодного климата Нарына (−30…−40 °C).

## Проблема
- Высокие затраты на отопление (уголь, электричество)
- Потери тепла при проветривании
- Плохое качество воздуха в домах зимой

## Решение
Компактный рекуператор тепла (HRV), который возвращает 70–90 % тепла из вытяжного воздуха, снижая расход энергии на 20–40 %.

## Презентация
См. файл `naryn_heat_recuperator.pptx`

Технология улучшает жизнь (экономия, комфорт, здоровье) и снижает вред природе (меньше сжигания угля).
